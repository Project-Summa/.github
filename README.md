# Project Summa — `.github`

This repository houses organization-wide GitHub configuration and community health files for [Project Summa](https://github.com/Project-Summa).

## What's here

- **Community health files** — Contributing guide, Code of Conduct, Security policy and License
- **Issue and PR templates** — Standardized templates for bug reports, feature requests and pull requests
- **Organization profile** — The [`profile/`](profile/) directory contains the README displayed on the [Project Summa organization page](https://github.com/Project-Summa)

## Other repositories

Summa development happens across multiple repositories:
